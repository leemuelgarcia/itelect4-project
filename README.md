# CourseTrack TS

Hi! This project was created for our ITELECT4 GT1 activity to practice the basic and advanced features of TypeScript.

The project is a simple course tracking system that uses users, courses, and submissions as sample data. Throughout the project, I applied different TypeScript concepts such as interfaces, type aliases, utility types, generics, enums, and strict type checking to better understand how TypeScript helps make code more organized and type-safe.

The main interfaces and types used in this project are **User**, **Course**, **Submission**, **ApiResponse<T>**, **ID**, **StringOrNumber**, **StudentWithCourse**, **UserUpdate**, **UserPreview**, **PublicUser**, **RoleCount**, **SubmissionStatus**, and **Role**.

To run the project, install the required packages first by using:

```bash
npm install
```

After that, run the project with:

```bash
npx ts-node src/index.ts
```

If you want to check if there are any TypeScript errors without creating JavaScript files, run:

```bash
npx tsc --noEmit
```
